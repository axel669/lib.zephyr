# Text
Simple component with some common props for types of text.

## Props

### notif _boolean_
Only used when putting text inside a [Toast](#/toast) element. Places the text
inside the content area of the toast without using a grid area macro.

### size _string_
Sets the size of the text using predefined sizes (setting text size via the ws
prop also works, these are just convenient and read a little nicer).

> Sizes are `info`, `subtitle`, `header`, and `title`.
